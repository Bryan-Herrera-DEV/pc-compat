# Usar PC Compat

1. Abre **Resumen** y espera el escaneo de Windows. Selecciona **Procesador**, **Gráficas**, **Memoria**, **Discos**, **Placa y BIOS** o **Sistema** para ver el inventario correspondiente.
2. En el primer inicio de un equipo de escritorio, indica la potencia de la fuente y las medidas libres para montar una gráfica si las conoces. Puedes omitirlas y volver a **Datos de instalación** cuando las hayas confirmado.
3. Abre **Catálogo** y elige una categoría. Busca por fabricante, nombre o SKU. Para gráficas, usa el modelo completo del ensamblador cuando conozcas su SKU.
4. Selecciona la pieza, indica cómo la vas a instalar y lee las comprobaciones del dictamen. Abre **Ver evidencia oficial** para consultar la ficha que respalda una comprobación.
5. Usa **Cobertura** para ver la fecha de la instantánea, las placas documentadas y sus listas oficiales.

## Ejemplo con una tarjeta gráfica

Busca `GT 710 2GD3H LP` y selecciona la variante MSI. Si tu placa tiene perfil, elige la ranura donde vas a instalarla. Comprueba el espacio libre y la ocupación de las ranuras adyacentes. El resultado separa el encaje del conector del ancho eléctrico que limita el enlace. [Ficha oficial MSI](https://www.msi.com/Graphics-Card/GT-710-2GD3H-LP/Specification)

## Después de cambiar hardware

Pulsa **Volver a detectar** para actualizar CPU, RAM, BIOS y los demás datos observables. Si cambiaste la fuente o el gabinete, actualiza también **Datos de instalación**.

Consulta [Cómo leer un dictamen](compatibilidad.md) para interpretar las condiciones y los datos pendientes.
