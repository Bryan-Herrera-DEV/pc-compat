# Colaborar con PC Compat

Aceptamos reportes de errores, correcciones documentales y propuestas de fichas en español o inglés. Usa el canal de incidencias que indique el mantenedor para el repositorio.

## Reportar un problema

Incluye la versión de PC Compat, la edición y compilación de Windows, los pasos para reproducirlo y el resultado esperado. Si afecta un dictamen, adjunta el nombre o SKU de la pieza candidata, el modelo y revisión de placa y el texto de la comprobación. Comparte únicamente los datos de inventario necesarios. [Privacidad](docs/privacidad.md)

## Proponer una ficha o corrección

| Dato | Qué incluir |
| --- | --- |
| Identidad | Categoría, fabricante, modelo exacto y SKU o revisión si corresponde. |
| Evidencia | URL HTTPS del fabricante. Para un PDF, indica página o sección. |
| Especificaciones | Valores con unidades, condiciones por CPU o revisión y diferencias entre variantes. |
| Impacto | Qué evaluación debería cambiar y por qué. |

Las fichas de tiendas, agregadores y foros pueden orientar la búsqueda. Para incorporar especificaciones se requiere la fuente oficial. [Mantenimiento del catálogo](docs/mantenimiento-catalogo.md)

## Cambios de código

Coordina los parches con el titular antes de enviarlos. Los cambios de código se aceptan por invitación y bajo los términos que acuerde el titular. La colaboración y el acceso a documentación se rigen por la [licencia propietaria](LICENSE.md).

Para una revisión autorizada, mantén el cambio enfocado, documenta la fuente de cualquier regla de hardware y registra las comprobaciones realizadas. [Desarrollo](docs/desarrollo.md) · [Validación](docs/validacion.md)
